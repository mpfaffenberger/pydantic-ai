01 / Get installed

Your new terminal teammate.

Install the Claude Code plugin, then CLAI2 from main.

1. Claude Code plugin
curl -fsSL https://raw.githubusercontent.com/mpfaffenberger/pydantic-ai-claude-code/main/install.sh | sh
2. CLAI2 + matching workspace packages
repo="git+https://github.com/pydantic/pydantic-ai.git@main"
uv tool install --overrides /dev/stdin "pydantic-clai2 @ $repo#subdirectory=src/pydantic_clai2" <<EOF
pydantic-ai-harness[coder] @ $repo#subdirectory=src/pydantic_ai_harness
pydantic-ai-slim[anthropic,mcp,openai] @ $repo#subdirectory=pydantic_ai_slim
pydantic-graph @ $repo#subdirectory=pydantic_graph
EOF
Prerequisites: uv + Git, macOS/Linux shell. Review the installer before running it. Then launch clai2.

02 / Connect your subscriptions

Sign in. Twice.

First / Codex
/login codex

Complete the browser sign-in.

Then / Claude Code
/login claude-code

Complete the Claude sign-in.

Codex also accepts /login openai-codex. If the Claude plugin lists claude instead, use /login claude. Run /login to see available connections.

03 / Stay on the edge

Fresh from main.

Open the settings menu and choose the bleeding update channel.

/set→updates.channel→bleeding
/set updates.channel bleeding
/update

The settings menu is /set in this checkout, not /settings. Bleeding follows main, so expect changes.

05 / Observability, sorted

Light it up in Logfire.

  1. Type /plugins → select observability.
  2. Press c to configure → Logfire project.
  3. Choose Self-hosted Logfire → enter logfire-eu.pydantic.info.
  4. Complete the browser OAuth sign-in.
  5. Pick logfire/clai2. Woot!

Check the destination before connecting: prompts, answers, and tool content are included by default.

06 / Turn on speculation

Don't wait.
Speculate.

Ctrl + XthenCtrl + S

Enable speculative execution in Monty.

Eligible read calls can start while the model is still writing code.

Press the two chords in sequence. The shortcut toggles the mode; check the status row to confirm it is on.
