01 / Get installed

Your new terminal teammate.

Install CLAI2. Add the Claude Code plugin if you'll use Claude.

Optional / Claude Code plugin
curl -fsSL https://gist.githubusercontent.com/mpfaffenberger/bd75c7b424ffdc6d81645bfe7de822d3/raw/install.sh | sh
2. CLAI2
uv tool install pydantic-clai2
Prerequisites: uv + a macOS/Linux shell. Review the installer before running it. Then launch clai2. Switch to bleeding and run /update on slide 3 to get the latest from main.

02 / Connect your account

Use your subscriptions!

Connect whichever you have: Codex, Claude Code, or GitHub Copilot.

Codex
/login codex

Complete the browser sign-in.

Claude Code
/login claude-code

Install the optional plugin, then sign in.

GitHub Copilot
/login github-copilot

Follow the device sign-in instructions.

Run /login to see available connections. One subscription is enough; connect more if you have them.

03 / Stay on the edge

Fresh from main.

Open the settings menu and choose the bleeding update channel.

/settings→updates.channel→bleeding

Then update to the latest build:

/update

Bleeding follows main, so expect changes.

05 / Observability, sorted

Light it up in Logfire.

  1. Type /plugins → select observability.
  2. Press c to configure → Logfire project.
  3. Choose Self-hosted Logfire → enter logfire-eu.pydantic.info.
  4. Complete the browser OAuth sign-in.
  5. Pick logfire/clai2. Woot!

Check the destination before connecting: prompts, answers, and tool content are included by default.

06 / Turn on speculation

Don't wait.
Speculate.

Ctrl + XthenCtrl + S

Enable speculative execution in Monty.

Eligible read calls can start while the model is still writing code.

Press the two chords in sequence. The shortcut toggles the mode; check the status row to confirm it is on.
